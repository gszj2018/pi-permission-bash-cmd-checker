# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-10-09

### Added

- `externalViewer` configuration to open the full bash command in an external viewer.

### Changed

- The command viewer shortcut now saves the full command to a session `.sh` file and opens it in the configured external viewer instead of a built-in overlay.

### Removed

- The built-in full-command overlay.

## [0.1.0] - 2026-10-08

Initial release.
