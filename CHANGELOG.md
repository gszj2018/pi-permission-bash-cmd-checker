# Changelog

All notable changes to this project will be documented in this file.

## [0.3.0] - 2026-10-15

### Added

- Hide the visible widget when a new prompt is submitted in the TUI (interactive input only).

### Changed

- README screenshots now reference the GitHub `media` branch raw URLs, and the `media` folder is no longer included in the published package.

## [0.2.1] - 2026-10-13

### Added

- Package gallery preview image through the `pi.image` manifest field.
- Screenshots in the English and Simplified Chinese READMEs.

## [0.2.0] - 2026-10-09

### Added

- `externalViewer` configuration to open the full bash command in an external viewer.

### Changed

- The command viewer shortcut now saves the full command to a session `.sh` file and opens it in the configured external viewer instead of a built-in overlay.

### Removed

- The built-in full-command overlay.

## [0.1.0] - 2026-10-08

Initial release.
